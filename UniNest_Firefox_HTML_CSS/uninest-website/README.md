# UniNest Freetown — DCOMP 204 Assignment 2

Responsive multi-page student accommodation website built with HTML5, CSS3 and vanilla JavaScript, based on the supplied UniNest wireframes.

## Pages
- `index.html` — Home / property search / featured properties
- `about.html` — About, mission, vision and values
- `services.html` — Services
- `features.html` — Major features
- `contact.html` — Contact form and FAQs
- `login.html` — Sign in / create account demo
- `dashboard.html` — Student dashboard
- `listings.html` — Searchable and filterable property listings
- `property-details.html` — Property details, amenities and viewing links

## Run the website
1. Extract the ZIP file.
2. Open the `uninest-website` folder.
3. Double-click `index.html` to open it in a browser. For a local development server, open the folder in VS Code and use Live Server.

## Features
- Responsive layouts for mobile, tablet and desktop
- Shared navigation and footer
- Mobile navigation menu
- Search by location, rent budget and property type
- Property filters and save/favourite buttons
- Contact form and demo sign-in/sign-up interactions
- Semantic HTML and accessibility labels

## Important notes
- The property names, prices, student dashboard counts and listings are demonstration content based on the provided wireframes. Confirm all information before publishing.
- Images load from Unsplash and require an internet connection.
- Search and form interactions run in the browser only. Login, messaging, booking, contact email, reviews and account creation are not connected to a backend/database. Do not enter real passwords.
- The assignment brief also lists screenshots, a GitHub repository and an A3 design board as deliverables. These source files cover the website code; create screenshots, publish the repository and prepare the A3 board separately.
