# UniNest Freetown 🏡

### Student Accommodation Platform

**UniNest Freetown** is a student accommodation website concept designed to help students in Freetown, Sierra Leone, explore housing options and connect with property owners.

The project aims to make the accommodation search process easier by presenting property information in a clear, accessible, and student-friendly format.

## 👨‍💻 Project Author

- **Name:** Prince M'bayinga-Kabia
- **Project:** UniNest Freetown
- **Project Type:** Web Design and Development
- **Location:** Freetown, Sierra Leone

## 🎯 Project Objectives

- Help students explore available accommodation options.
- Present property information in an organised format.
- Provide a user-friendly interface for browsing housing services.
- Promote awareness of accommodation costs, amenities, and property details.

## 🛠️ Technologies Used

- **HTML5** — Website structure and content.
- **CSS3** — Styling, layout, colours, and responsive design.
- **GitHub** — Source code hosting and project version management.

## 📄 Website Pages

The project includes the following pages:

- Home
- About
- Services
- Major Features
- Property Listings
- Property Details
- Contact
- Login and Sign Up

## 🚀 How to Run the Project

1. Download or clone this repository.
2. Open the project folder in Visual Studio Code.
3. Locate `index.html`.
4. Open it in a web browser, such as Firefox.

## 📌 Project Status

This project is a student web design demonstration. Website features are presented as part of the interface, and functions requiring a backend or JavaScript may not be operational.
