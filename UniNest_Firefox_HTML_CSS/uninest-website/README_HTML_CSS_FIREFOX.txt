UNINEST FREETOWN — HTML + CSS ONLY

OPEN IN FIREFOX
1. Extract this ZIP to a folder on your computer.
2. Open the uninest-website folder.
3. Double-click OPEN_IN_FIREFOX.bat.
   If Firefox is not found, open index.html, right-click it, choose Open with, then Firefox.

EDIT IN VISUAL STUDIO CODE
1. Open VS Code > File > Open Folder.
2. Select the uninest-website folder.
3. Edit the .html pages for content and assets/style.css for colours/layout.

This project contains HTML and CSS only; JavaScript has been removed.
Photos are stored in assets/images. Some page functionality such as real login, booking, and live search requires a backend or JavaScript and is not active in this static version.
